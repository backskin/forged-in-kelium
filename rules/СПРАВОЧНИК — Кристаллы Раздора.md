# Приложение А. Карты приказов

16 карт приказов — четыре колоды по четыре — и 4 карты
БЕЗОПАСНОСТЬ. Каждый игрок играет одной колодой плюс своей БЕЗОПАСНОСТЬЮ.
Спец-плашка напечатана на 12 картах из 16: у каждой колоды ровно один
спец каждого вида и ровно одна карта без плашки.

| Колода | Верхний приказ | Нижний приказ | Спец-плашка |
|---|---|---|---|
| Голубая | Инфраструктура | Разработка | ЗАДАНИЕ |
| Голубая | Разработка | Приобретения | — |
| Голубая | Приобретения | Наступление | МОНЕТА |
| Голубая | Наступление | Инфраструктура | ДВИЖЕНИЕ |
| Алая | Инфраструктура | Приобретения | ДВИЖЕНИЕ |
| Алая | Разработка | Инфраструктура | МОНЕТА |
| Алая | Приобретения | Наступление | — |
| Алая | Наступление | Разработка | ЗАДАНИЕ |
| Зелёная | Инфраструктура | Наступление | МОНЕТА |
| Зелёная | Разработка | Приобретения | ЗАДАНИЕ |
| Зелёная | Приобретения | Разработка | ДВИЖЕНИЕ |
| Зелёная | Наступление | Инфраструктура | — |
| Жёлтая | Инфраструктура | Разработка | — |

| Жёлтая | Наступление | Наступление | МОНЕТА |

**БЕЗОПАСНОСТЬ — 4 карты.** Все восемь действий, играй любые два разных; нижнего приказа нет.
