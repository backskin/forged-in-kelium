# rules/ — правила игры

Правила игры «Келемий. Кристалл раздора» пишутся заново, по главам:
`Книга правил — черновик/`.

| Файл | О чём |
|---|---|
| `Книга правил — черновик/00 — План книги.md` | какие книги и главы, общие решения |
| `Книга правил — черновик/Решения дизайнера.md` | подтверждённые правила, на которые опираются главы |
| `Книга правил — черновик/NN — …` | черновые составы и тексты глав |
| `КНИГА МИРА — Келемий.md` | мир игры: Плуг и Шов, келемий и срост, свищи, Межевой устав, Литерный, четыре стола, сезон у Сорочьего брода, словарь мира, варианты названия |
| `СПРАВОЧНИК — Кристаллы Раздора.*` | списки карт, иконки, раскладки; собирается из данных |
| `КОНТЕЙНЕРЫ 2.0 — …`, `Планшет войск — …`, `Планшет технологий — …` | спецификации печати и арта, не правила |

Машинный свод, по которому играет движок, — `data/rulesets/`.
