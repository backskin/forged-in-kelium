# Правила — оригинал

Эти файлы — единственный источник правды по правилам игры. Других копий нет:
Яндекс.Диск больше не используется для хранения текста правил и решений по
игре и разработке. Всё, что раньше жило в рабочей папке дизайнера как
отдельные `.md`-документы, теперь здесь, в репозитории.

## Как с этим обращаться

**Эти файлы редактируются прямо здесь.** Поменялось правило — правь файл в
этой папке и коммить. Никакой второй копии, которую нужно было бы обновлять
следом, больше не существует.

Решения по игре и разработке, которые не являются правилами напрямую
(журнал решений, бэклог, заказы на инструменты, разборы карт, арт-гайды),
лежат в `../design-docs/`.

Числа, по которым реально играет движок, лежат не здесь, а в `data/rulesets/` —
там машинная версия правил. Расхождение между текстом и данными означает ошибку
в одном из двух, и разбирать её нужно, а не выбирать удобное.
