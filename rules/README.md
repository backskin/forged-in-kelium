# rules/ — правила игры

| Что | Где | Роль |
|---|---|---|
| Книга правил | `Книга правил — черновик/00 … 11 — *.md` | **нормативный текст правил**; вёрстка — `вёрстка/`, сборщики — `tools/книга/` |
| Решения дизайнера | `Книга правил — черновик/Решения дизайнера.md` | журнал решений Влада с датами: что решено и где менять |
| Словарь | `СЛОВАРЬ — термины игры.md` | **все слова игры**: книга, карты, памятки, интерфейс и документы говорят только словами отсюда |
| Книга мира | `КНИГА МИРА — Келемий.md` | канон предыстории |
| Картинки книги | `иконки/`, `иконки-экспорт/`, `жетоны модулей/`, `фон/`, `иллюстрации/` | ассеты, которые вставляют главы и сборщики |
| Разъяснения карт | `разъяснения-заданий.yaml`, `разъяснения-арсенала.yaml` | данные для справочника |

Машинный свод, по которому играет движок, — `data/rulesets/<версия>.yaml`
(цифровая версия открывается со свода `GameConfig.GAME_RULESET`). Правило
меняется разом в трёх местах: свод (ключ), книга (текст), «Решения дизайнера»
(запись с датой).

Старые спецификации печати, прежние книги и справочники — в
`../archive/rules/`.
