# rules/ — правила игры

## Источник правды — один

**`РУЛБУК — Кристаллы Раздора.md`** — полные правила настольной игры: что в
коробке, как раскладывается, что игроки делают руками. При расхождении с любым
другим документом проекта **прав рулбук**.

Второй равноправный источник — **машинный свод** `data/rulesets/1.35.0.yaml`:
по нему играет движок. Рулбук и свод обязаны совпадать; расходятся — это баг, и
чинить надо оба.

Приложения рулбука (полные списки карт) **собираются из данных**:

```bash
python tools/приложения-рулбука.py
```

Правила выше меток `<!-- ПРИЛОЖЕНИЯ -->` скрипт не трогает. Пересобрал колоду —
пересобери приложения.

рулбуком, но сами правила они не задают.
