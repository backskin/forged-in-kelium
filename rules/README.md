# Правила — КОПИЯ, а не оригинал

Здесь лежит **копия** документов правил. Оригиналы живут в рабочей папке
дизайнера (Яндекс.Диск, «Forged in Kelium»), и правятся только там.

## Как с этим обращаться

**Эти файлы не редактируются.** Их перезаписывают целиком свежей копией из
рабочей папки, когда правила поменялись. Любая правка, сделанная прямо здесь,
потеряется при следующей перезаписи и разойдётся с оригиналом.

Нужно поменять правило — правь оригинал в рабочей папке, потом обнови копию.

## Зачем копия вообще нужна

Репозиторий должен быть самодостаточным: по нему одному видно, из каких правил
собран движок, какие числа он реализует и почему. Без правил рядом код читается
как набор формул без источника.

## Что здесь лежит

| Файл | О чём |
|---|---|
| `ПРАВИЛА — единственный источник правды.md` | главный документ, всё остальное подчинено ему |
| `СВОД — механика игры (для работы над картами).md` | механика в разрезе карт |
| `Действия — полный свод.md` | восемь действий подробно |
| `Бой — полные правила (источник правды).md` | бой, уничтожение, трофеи |
| `Победные очки — все источники и экономика.md` | откуда берутся очки |
| `Конец игры, ЦУ и супер арсенал.md` | условия конца партии |

Числа, по которым реально играет движок, лежат не здесь, а в `data/rulesets/` —
там машинная версия правил. Расхождение между текстом и данными означает ошибку
в одном из двух, и разбирать её нужно, а не выбирать удобное.
