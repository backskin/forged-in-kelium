# СЛОВАРЬ — термины игры

Редакция 13.10.2026. Сверено с книгой правил (главы 00–11 после правок
12–13.10) и сводом 1.51.0.

## Правило словаря

**Одно понятие — одно слово, и это слово берётся отсюда.** Книга правил,
памятки, тексты карт, подписи цифровой версии, справочник, документы,
передачи дел и разговоры о правилах говорят только словами из этого файла.
Это касается не только предметов, но и событий, действий, эффектов,
розыгрышей и состояний.

Откуда берутся слова — по порядку:

1. **Общепринятые слова настольных игр** (раздел 1). Колода, сброс, рука,
   рубашка, жетон, раунд, фаза, ход, первый игрок, победные очки — то, что
   игрок уже знает по другим настолкам. Своё слово вместо общепринятого не
   придумываем.
2. **Обычный русский язык** — если общепринятого игрового слова нет:
   «поставить», «снести», «заплатить», «соседний».
3. **Наши термины** (разделы 2–9) — только когда без нового понятия правило
   не сказать. Термин заводится один раз, получает определение и дальше
   используется везде одинаково.

**Нового слова нет в словаре — сначала словарь, потом текст.** Нужное слово
сперва ищут здесь; нет — проверяют, нельзя ли сказать уже имеющимися;
только если нельзя — добавляют сюда с определением и датой, и лишь потом
пишут в правила или на карту. Самодельные слова «для красоты» запрещены:
каждое новое слово — это лишнее, что игроку придётся выучить.

Пишем так:

- Названия действий — с большой буквы: Добыча, Питание, Снабжение,
  Командование, Развитие; их варианты тоже: Манёвр, Бой, Рынок, Наука.
- Названия приказов — прописными: ОСВОИТЬ, МОБИЛИЗОВАТЬ, НАСТУПАТЬ,
  КОНТРОЛИРОВАТЬ, ИССЛЕДОВАТЬ.
- Сокращения — только где нет места (карты, иконки, таблицы): ЦУ, БПР, ПО.
  В прозе — «боеприпас», «победные очки»; ЦУ пишется сокращением всегда.
- Числа на компонентах называем тем, что нарисовано: кружок действия — это
  «действие», сердечки — «прочность», шестерёнки — «трофеи».

## 1. Общепринятые слова настольных игр

| Слово | Что значит у нас |
|---|---|
| **партия** | вся игра от подготовки до подсчёта очков; «игра» — о самой настолке, не о партии |
| **подготовка** | всё, что делают до первого раунда (глава 3) |
| **раунд** | три фазы: Обновление, Управление, Возвращение |
| **фаза** | часть раунда |
| **ход** | то, что игрок делает по своей вскрытой карте приказа |
| **первый игрок** | тот, у кого фишка первого игрока; ходит первым в каждом круге |
| **по часовой стрелке / против часовой** | порядок ходов и передачи фишки первого игрока |
| **поле** | общая карта из гексов |
| **гекс** | шестиугольная ячейка поля |
| **жетон** | картонная фишка игрока или поля |
| **кубик** | деревянный кубик ресурса, энергии или технологий |
| **планшет** | личный лист игрока (планшет войск, планшет хранилища) или общий (планшет науки, планшет рынка) |
| **колода** | стопка карт рубашкой вверх; карту **берут с верха колоды** |
| **сброс** | стопка использованных карт колоды лицом вверх; **сбросить** — положить туда |
| **перемешать** | кончилась колода — её сброс перемешивают, и он становится колодой |
| **рука** | карты, которые игрок держит закрыто от соперников |
| **рубашка / лицо** | обратная и лицевая сторона карты; «рубашкой вверх», «лицом вверх» |
| **вскрыть** | перевернуть свою закрытую карту лицом вверх |
| **сыграть / разыграть** | выполнить то, что даёт карта, действие или плашка |
| **запас** | личный: свои жетоны не на поле; **общий запас** — монеты и кубики у поля |
| **ресурс** | монета, келемий, боеприпас, трофей |
| **цена** | сколько монет (или ресурсов) платят; **заплатить** — вернуть в общий запас |
| **эффект** | что делает карта: **разовый** (один раз) или **постоянный** (пока карта лежит) |
| **победные очки** | звёзды; в прозе «победные очки» или «очки» |
| **подсчёт очков** | после конца партии (глава 11) |
| **мгновенная победа** | кончает партию сразу, очки не считают |
| **равенство** | одинаковая сумма очков; решается по признакам из главы 11 |
| **соперник** | любой другой игрок; не «враг», не «противник» в правилах |

## 2. Партия и раунд

- **Обновление** — первая фаза: свалка, рынок, первый игрок.
- **Управление** — вторая фаза: 4 **круга**; в круге сначала **выбор** (все
  одновременно кладут карту приказа рубашкой вверх), потом **ходы** по
  очереди.
- **Возвращение** — третья фаза: конец партии, трофеи, приказы в руку.
- **Свалка** — карта приказа, отложенная в Обновлении рубашкой вверх на весь
  раунд; на неё кладут уничтоженные вами чужие жетоны оборотом вверх.
- **Фишка первого игрока** — переходит к соседу против часовой стрелки.

## 3. Приказы и действия

- **Карта приказа** — 5 у каждого игрока, своего цвета. Названия приказов:
  ОСВОИТЬ, МОБИЛИЗОВАТЬ, НАСТУПАТЬ, КОНТРОЛИРОВАТЬ, ИССЛЕДОВАТЬ.
- **Верх карты** — два действия своего приказа. **Низ карты** — название
  другого приказа и одно из его действий.
- **Совпадение** — в этом круге до вас уже вскрыли такую же карту: верх даёт
  одно действие из двух.
- **Низ открыт / закрыт** — открыт, если карту с названием из низа в этом
  круге уже вскрыли до вас; закрытый низ ничего не даёт.
- **Действие** — одно из пяти: **Добыча, Питание, Снабжение, Командование,
  Развитие**. У каждого два **варианта**, разыгрывают один:

  | Действие | Варианты |
  |---|---|
  | Добыча | Добыть / Построить добытчик |
  | Питание | Переложить энергию / Построить энергостанцию |
  | Снабжение | Выпустить / Построить военное здание |
  | Командование | Манёвр / Бой |
  | Развитие | Рынок / Наука |

- **Одно действие — один раз**: за ход картами приказов каждое действие
  разыгрывается один раз; второй раз его дают только другие карты.
- **Спец-действие** — одно за ход, сверх действий; знак ▶. Не «СПЕЦ» в прозе.
- **Спец-плашка** — на 4 картах приказов из 5: **Монеты**, **Боеприпас**,
  **Задание**, **Движение**. Карта без плашки у каждой нации своя.
- **Нация** — синие, красные, зелёные, жёлтые; у каждой свои планшеты,
  жетоны и плашки. Не «фракция» в правилах.

## 4. Поле

- **Наземный сектор** — одно из 6 мест по краям гекса; **небо** — центр
  гекса, место авиации.
- **Сторона гекса**, **соседний гекс** (общая сторона).
- **Стенка** — сектор здания, обращённый к соседнему гексу; чужая стенка
  закрывает сторону для наземных войск.
- **Зона стройки** — гексы со своими зданиями и соседние за своей стенкой.
- **Тайл зарождения** — тайл с келемием: **стартовый** или **большой**;
  у него **лицо** и **оборот**; **опустел** — на нём не осталось келемия.
  Кратко — **зарождение**.
- **Недоступный гекс** — нельзя встать, пройти, пролететь.
- **Контейнер на поле** — нарисован на секторе или в небе; **открыт**, пока
  не накрыт жетоном.
- **Место для энергостанции** — круг на секторе; станция даёт энергию, только
  стоя на нём.
- **Нейтральная постройка** — ничья, на 1 или 2 сектора; стенка для всех.
  **Гарнизон** — место для 1 пехоты в постройке на 2 сектора.
- **Перемещение** — шаг за шагом в соседний гекс, не дальше скорости.
  **Телепортация** — эффект карты переставляет жетон без пути.
- **Скорость** — на сколько гексов перемещается жетон рода войск.

## 5. Жетоны

- **Здания:** **ЦУ** (центр управления, род мужской: «ЦУ запитан»,
  «ЦУ уничтожен»), **военные здания** — казарма, завод, авиабаза,
  **добытчики №1–4**, **энергостанции №1–4**.
- **Войска** — пехота, техника, авиация, вышка; каждая — **род войск**.
  Один жетон — «жетон пехоты», «жетон войск». Не «юнит», не «отряд».
- **Поставить / построить** здание — за цену в зону стройки. **Снести** —
  вернуть своё здание с поля в запас (+1 монета). **Уничтожить** — чужой
  жетон, в Бою.
- **Прочность** — сколько урона выдерживает жетон; сердечки. Не «здоровье».
- **Оборот** жетона — сторона, которой он лежит на свалке: шестерёнки
  (трофеи) и контейнеры владельцу.
- **Выпуск** — что делает военное здание или ЦУ в варианте «Выпустить»:
  жетоны войск своего рода или боеприпасы, сколько напечатано на планшете
  войск.

## 6. Энергия

- **Энергия** — кубики энергии. Не тратится, а лежит и перекладывается. Не
  говорим «трата энергии», «сброс энергии».
- **Источник** — даёт кубики: ЦУ, энергостанции, жетон хранилища стороной
  энергии.
- **Потребитель** — здание с **ячейками энергии**: ЦУ, военные здания,
  добытчики.
- **Запитан** — во всех ячейках здания лежат кубики (ЦУ — хотя бы один).
  На компонентах — «запитанные ⚡». Не «с энергией».
- **Здание без энергии** — не запитано; даёт одну штуку на выбор: добытчик —
  1 келемий или 1 карту контейнера, военное здание и ЦУ — 1 жетон войск или
  1 боеприпас. **Запитанное** здание даёт оба своих выхода сразу, сколько
  напечатано (с 13.10.2026).
- **Переложить энергию** — вариант Питания: любые свои кубики между
  источниками и ячейками.

## 7. Ресурсы и хранилище

- **Монеты** — жетоны в общем запасе и у игрока.
- **Келемий, боеприпасы, трофеи** — кубики в хранилище. **Трофей** — валюта
  Науки; на обороте жетона — шестерёнки.
- **Хранилище** — **ячейки хранилища** на планшете хранилища, по кубику в
  ячейке; не путать с **ячейкой энергии**.
- **Жетон хранилища** — награда зелёного трека: сторона **ячейки** или
  сторона **энергии**; обычная и золотая.

## 8. Бой и модули

- **Бой** — вариант Командования: атака по одному **гексу-цели** войсками с
  соседних гексов.
- **Атака** — удар одного жетона войск по одному жетону: **универсальная**
  (2 боеприпаса, любой вид) или **специальная** (1 боеприпас, вид на
  планшете войск или на модуле боя).
- **Урон** — кубик боеприпаса на атакованном жетоне. **Уничтожен** — урона
  столько, какова прочность; жетон уходит на свалку атакующего.
- **Манёвр** — вариант Командования: вывести войска с гекса и ввести на него.
- **Модуль сборки** (синий мешочек) — на ячейку военного здания, меняет
  выпуск. **Модуль боя** (красный) — на специальную атаку, даёт два вида
  целей. **Модуль блокировки боя** — с подготовки закрывает одну
  специальную атаку; его род войск — ваше стартовое войско. **Забранный
  модуль** — снятый с планшета владельца уничтоженного ЦУ, 3 звезды.
- **Золотая сторона** — сторона модуля или жетона хранилища со звездой;
  **улучшить** — перевернуть золотой стороной.
- **Перенос модуля** — переложить модуль на другую ячейку того же вида.
- **Военная победа** — уничтожить любой ЦУ, уже имея забранный модуль.

## 9. Карты, Рынок и Наука

- **Колоды:** задания, арсенал, контейнеры, рынок, супер-задания,
  супер-арсенал; **начальные задания** и **начальный арсенал**.
- **Сжечь** — сбросить карту ради верхнего эффекта; знак зачёркнутой карты.
- **Верх карты / верхний эффект** — разовый эффект вверху карты, ради
  которого её сжигают. **Свободный верх** — со знаком ∞: сжигают без
  спец-действия.
- **Задание:** **требование** → **награда** (действие, одно из двух, сверх
  приказов); **дополнительное требование** → его награда. **Выполнить
  задание** — спец-действием.
- **Арсенал:** **закрытая** карта — рубашкой вверх в запасе; **установить**
  — спец-действием лицом вверх в ячейку под планшетом войск;
  **установленная** карта даёт **постоянный эффект** и, бывает,
  **спец-способность**. Одно название — одна установленная карта.
- **Ячейки под планшетом войск** — три: 1 установленная карта арсенала или
  2 карты контейнеров.
- **Контейнер** — карта; её берут, когда жетон накрыл открытый контейнер
  на поле, и **вскрывают** спец-действием.
- **Карта рынка** — одна открытая на раунд; **предложение** — что на ней
  можно взять; **ячейка обновления** — куда кладут келемий, чтобы
  **обновить** карту (не путать с фазой Обновление).
- **Трек технологий** — красный, синий, зелёный; **ступени** 1–4, **вершина**
  — последняя. **Кубик технологий** встаёт на ступень. **Шаг по треку** —
  встать на следующую ступень; **перепрыгнуть** — пройти занятую.
- **Обмены Научного отдела** — перенос модуля, улучшение модуля, карта
  арсенала; только за трофеи.
- **Победа наукой** — свои кубики на вершинах всех трёх треков.
