:вовсю:

Жетоны зданий: ЦУ, казарма, завод и авиабаза — по 1, добытчики
и энергостанции — по 4. Жетоны войск: пехота, техника, авиация и вышка —
по 4. Жетонов ограниченное число: выставить можно только те, что есть
в наборе.
