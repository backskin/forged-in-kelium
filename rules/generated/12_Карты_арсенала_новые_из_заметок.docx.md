# **Что учесть при вводе**

Общие вопросы, которые всплывают сразу по нескольким картам.

| Вопрос | Что именно | Решение |
| :---- | :---- | :---- |
| **Утиль-эффекты ограничены реализованным набором** | **В чём дело:** верх карты может быть только тем, что движок умеет: выдача ресурсов и карт (gain) и бесплатное действие любого из восьми (free\_action). Карта с иным верхом изымается из колоды на подготовке. **Что сделано здесь:** все предложенные утили взяты из этого набора, поэтому карты можно вводить, не трогая код верхов. |  |
| **Четыре карты требуют только данных, восемь — кода** | **Только данные:** «Второй контур» и «Десантные тропы» ложатся на уже написанные точки правил; «Параллельные штабы» используют готовую пассивку (новая только оговорка про Безопасность); «Трофейный сейф» сводится к вместимости склада. **Нужен код:** «Переформирование», «Новая жила», «Маркшейдер», «Абордаж», «Сходу в строй», «Обмен пленными», «Передовая база», «Полевые окопы». |  |
| **Три карты пересекаются с общими правилами** | **Какие:** «Аварийное питание» — со сводным правилом об оплате недостающей энергии монетой; «Трофейный сейф» — с тем, что трофеи и так лежат в любых ячейках; «Передовая база» — с платным переносом зданий. **Что решить:** карта должна давать что-то СВЕРХ общего правила, иначе она пустая с первого дня. |  |
| **Правило примыкания широкой стенкой** | **В чём дело:** оно упоминается в вашей заметке про добытчик и подразумевается «здесь и далее», но в правилах отдельным текстом не записано. **Что решить:** записать один раз общим правилом — на него будут ссылаться и карты, и стройка. |  |
| **Захват и выкуп трогают трофейную экономику** | **В чём дело:** «Абордаж» и «Обмен пленными» вынимают жетоны из трофейного оборота, на котором держится Наука и треть очков партии. **Что решить:** считается ли захват уничтожением (задания, счётчик, ответный бой) и что противник получает взамен. |  |
