# **Карты супер-арсенала — как устроены сейчас**

**Источник:** data/cards/super\_arsenal.1.0.0.yaml (подключён сводом 1.10.0), структура треков — data/boards/boards.1.0.1.yaml, числа шагов — свод 1.10.0 \+ код kelium.engine.Setup / Actions / Passives / CombatResolver / Scoring. 17.08.2026.

**Что здесь:** все девять карт — четыре супер-войска и пять способностей, — плюс то, как карта вообще попадает к игроку. Отдельной колонкой — работает способность в движке или только записана.

**Как читать:** средняя колонка — что напечатано на карте и как это устроено в коде. Правая — пусто, для ваших пометок.

## **Как карта попадает к игроку**

| Правило | Как устроено сейчас | Комментарий / правка |
| :---- | :---- | :---- |
| **Раскладка на подготовке** 3 карты из 9 | Открыто с первого хода и до конца партии. **Как устроено:** девять карт тасуются, по одной ложится ЛИЦОМ ВВЕРХ на вершину каждого из трёх треков планшета технологий. Остальные шесть в коробку — в этой партии их нет. **Как реализовано:** Setup: перемешивание и раскладка по трекам; раскладка видна в проигрывателе (BoardsPanel). |  |
| **Вершина трека** шаг 4 одна ячейка | Приз достаётся ровно одному игроку на трек за партию. **Цена и награда:** шаг 4 стоит 4 трофейных очка, ячейка на вершине одна и даёт 3 ПО за шаг ПЛЮС лежащую там карту супер-арсенала (step\_rewards: prize\_cube, module, module, super\_arsenal\_card). **Чем это ещё важно:** занятие всех трёх вершин — одно из условий конца партии, так что каждый забранный приз ещё и приближает финал. |  |
| **Отсев нереализованного на супер-арсенал не действует** внимание | Правило ревизии «реализовать либо изъять» здесь не применяется. **Как устроено:** карты обычного арсенала, контейнеров и рынка с нереализованными эффектами изымаются из колоды на подготовке. Супер-арсенал через этот фильтр не проходит. **Следствие:** карта с неработающей способностью (sa5) может лечь на вершину трека и стать призом за 4 трофея. |  |
| **Символов супер-арсенал не несёт** символы | Разметка символов супер заданий его не касается. **Как устроено:** символы печатаются на 24 обычных картах арсенала и на части контейнеров; стартовые и супер-арсенал их не несут, чтобы старт и вершина трека не давали набор символов даром. |  |

# **Что не сходится — на решение**

Расхождения и вопросы по набору. Правая колонка — за вами.

| Место | Что именно | Решение |
| :---- | :---- | :---- |
| **«Штабная директива» — пустой приз** | **В чём дело:** пассивка ignore\_coincidence не реализована и помечена inert, но карта остаётся в наборе и может лечь на вершину трека. **Чем грозит:** один из трёх призов партии может оказаться пустым, при том что вершина стоит 4 трофея и приближает конец игры. **Возможное решение:** реализовать пассивку, убрать карту из набора либо распространить отсев нереализованного на супер-арсенал. |  |
| **Супер-войско вне лимита рода** | **В чём дело:** супер-жетон не считается в личный запас рода, то есть это пятый жетон сверх четырёх. **Чем грозит:** предел «4 жетона каждого рода», введённый после замера, для владельца карты сдвигается. **Возможное решение:** подтвердить, что так и задумано, либо считать супер-жетон в запас рода. |  |
| **Разброс силы приза** | **В чём дело:** четыре карты дают жетон войска и 1 ПО, «Мандат совета» — просто 2 ПО, «Параллельные штабы» — второе СПЕЦ каждый ход. **Чем грозит:** три случайные карты означают, что в одной партии вершины дают очки, в другой — темп; ценность подъёма по треку скачет между партиями. **Возможное решение:** решить, вариативность это или перекос, и при необходимости выровнять по одному классу приза на трек. |  |
| **Вторая атака бьёт шире, чем обещает текст** | **В чём дело:** тексты всех четырёх карт говорят про атаку «по вышкам», а цель в движке — «здания и вышки», то есть любое здание противника, включая ЦУ. **Чем грозит:** супер-жетон оказывается осадным оружием, чего по тексту карты не видно; это прямо влияет на военную победу через ЦУ. **Возможное решение:** либо сузить цель до вышек, либо переписать тексты под «здания и вышки». |  |
