## 1. Команды

```
python tools/книга/reflow.py <номер главы>     # перевёрстка одной главы книги правил
python tools/книга/build.py                    # HTML → PDF (печатный + просмотр + несжатый)
python tools/книга/справочник_книга.py         # собрать справочник целиком
powershell -ExecutionPolicy Bypass -File tools/раскладки-в-png.ps1   # перерисовать раскладки
mvn -o -q -pl gui -am -DskipTests package      # сборка движка и интерфейса
```

Питону нужен `PYTHONIOENCODING=utf-8`, иначе он падает на кириллице в выводе.

**Справочник кладёт PDF в `tools/книга/spravochnik.pdf`, а не в папку вёрстки.**
После сборки файл копируется в `rules/Справочник — черновик/вёрстка/Справочник.pdf`
руками — это не автоматизировано.

- Вчетвером — **все восемь** авторских, на двух полосах, в шапке «1 из 2».
- Какой файл в какую картинку идёт — списком в `tools/раскладки-в-png.ps1`.

**Подбор сборки переписан** (`engine/.../BlockAssembler.java`). Раньше перебор
искал минимум чёрных накладок и отдавал ЛЮБУЮ сборку с этим минимумом, отчего
блок ложился «вдоль» и поле выходило вытянутым. Теперь среди равных по
накладкам сборок выбирается лучшая по компаратору `ПО_КАЧЕСТВУ`:

1. меньше чёрных накладок;
2. форма ближе к квадрату (считается по настоящим размерам картона, а не по
   осевым координатам — гекс шире, чем выше);
3. ровный расход больших и малых блоков, сборка вовсе без большого штрафуется;
4. при прочих равных — меньшая площадь.

`solveVariants` набирает запас вариантов (не меньше 12) и сортирует их, поэтому
и кнопка «Другая сборка» в конструкторе идёт от лучшей к худшей. Тесты —
`engine/src/test/java/kelium/КачествоСборкиTest.java`.

## 6. Грабли — прочитать до правок

- **Главу 3 не перевёрстывать** `reflow.py`: её разворот собирает
  `make_spread.py`, перевёрстка его затрёт.
- **`reflow.py` требует, чтобы в md стояли `<!-- стр -->`.** Если в html
  разрывы есть, а в md нет — глава развалится. Так уже терялись главы 1, 2, 3
  (восстанавливались через `git checkout`).
- **`restyle.py` переписывает весь `<style>`.** Любой новый CSS живёт там,
  иначе пропадёт при следующей перевёрстке.
- **`ReplayRecord.HexState.sideOwner` — только для зданий.** `FieldPainter`
  считает размеченные стороны занятыми; uid войск туда писать нельзя, жетон
  «съезжает» с гекса. На этом ловились иллюстрации полос 10 и 13.
- **`FieldPainter.paintNeutral` молча не рисует нейтраль с одним углом**
  (`corners.size() < 2`).
- **Bash-инструмент калечит `\\n` в heredoc.** Питоновские правки файлов
  пишутся через `chr(92)` либо через отдельный файл скрипта, иначе в исходник
  попадает настоящий перенос строки и получается синтаксическая ошибка.
- **`PrintedContainersTest.shuttlingBetweenTwoContainerCellsGivesNothing`
  красный.** Проверено на чистом HEAD — падал и до правок этой смены, к
  вёрстке отношения не имеет. Первый заход войском с обычного гекса на
  контейнерную ячейку даёт 0 карт вместо 1.
- **Набор рынка 3.0.0 закоммичен вторым чатом** (`8c909ae`, «Рынок 3.0:
  десять карт, обновление за келемий»): `СделкиНаРынке3.java`, подключение
  в `MarketPack`, `market.deck_size` в `Setup` (регулятор длины партии),
  `usedMarketRefresh` в журнале хода, четыре новых файла в `bots`. Всю смену
  эти правки лежали в рабочей копии и в коммиты вёрстки не входили — если
  в справочнике надо показать десять карт рынка вместо восьми, пересобрать
  его заново.

## 7. Название игры — отложено

Разговор о переименовании остановлен по решению дизайнера; здесь только то,
что успели нарыть, чтобы не собирать заново.

Повод: на выставке и в чате любителей настолок название «Келемий. Кристалл
раздора» разнесли — вместо вычитки правил два часа обсуждали имя.

Собран свод: **`design-docs/нейминг/BGG — названия игр наших жанров.md`** —
383 игры наших жанров с BGG (экономика + территория/конфликт, от 300 оценок),
у каждой название, год, оценка, о чём она и связь названия с содержимым.
Официальный API BGG закрыт (`Unauthorized`), живые страницы держит Cloudflare,
поэтому взята готовая выгрузка BGG на 10 тысяч ранжированных игр.

Что показали цифры:

- одно-два слова — 72 % выборки и 42 из 50 самых известных игр;
- подзаголовок — редкость (18 %, и почти всегда это серия);
- **51 % названий в жанре не называют ничего напрямую** (Carcassonne, Caylus,
  Spyrium, Tikal, Scythe) — упрёк «выдуманное слово ничего не значит» бьёт
  мимо, проблема нашего имени в длине и двухэтажности;
- гнездо «добыча и производство» почти пустое: 7 игр на 383.

Направление, к которому пришли: одно короткое русское слово с двойным дном —
горно-производственное значение (мир игры) и конфликтное (что за столом).
Финалисты обсуждения: **Добыча**, **Карьер**, **Передел**; в запасе — Забой,
Обвал, Разлом. Кристалл при этом остаётся ресурсом и картинкой, но перестаёт
быть именем. Ничего не решено, к теме вернуться отдельно.
