# КАТАЛОГ КИРПИЧИКОВ — что карта может проверить и что может дать (черновик 1, 30.09.2026)

Этап 1 плана «фигуры и синергии». Это не список синергий, а словарь, из которого
программа потом переберёт все сочетания. Здесь нет оценок «хорошо/плохо» и нет
готовых карт. Каждый кирпичик обязан быть:

- **виден со стола** — по жетонам, планшетам, картам (правило «только из компонентов»);
- **рисуем или пишем** на карте 56 × 87 мм без сносок;
- **проверяем движком** однозначно.

Термины — только из книги правил и словаря (главы 4, 6, 8; канон фигур 12–13.08.2026).

---

## A. Наследие: как устроены требования сейчас

Три вида требования (по печати): **состояние** (держится само, видно глазами),
**происшествие** («в этот ход …»), **жертва** (сдай …). У заданий есть
дополнительное требование с наградой-ресурсами и верх (разовый эффект сжигания).
У арсенала — постоянный эффект, спец-способность, верх.

Позиционные требования сейчас все из одного отношения: своё здание рядом с
чужим, своё войско на гексе чужого здания, стенка к войскам врага, войска на N
гексах, два добытчика примыкают. Нарисованных фигур и «кем» — нет.

## B. КТО — что стоит на поле

| Группа | Кирпичики |
|---|---|
| Войска | пехота, техника, авиация, вышка |
| Здания | ЦУ, казарма, завод, авиабаза; добытчик № 1–4; энергостанция № 1–4 |
| Обобщения | войско (любое), наземное войско, военное здание, источник энергии, потребитель энергии, здание (любое) |
| Ничьё | нейтральная постройка на 1 и на 2 сектора (гарнизон); тайл зарождения (с келемием / выработанный); открытый контейнер на секторе; круг энергии; недоступный гекс |
| Состояние жетона | урон (сколько кубиков), целый (без урона), запитан / не запитан, номер здания (1–4 у добытчика и энергостанции), пехота в гарнизоне, авиация в небе |

## C. ЧЬЁ

своё; чужое — любого соперника; чужое — **одного и того же** соперника; чужое —
лидера (по очкам / по войскам на поле / по келемию — как у «Охоты на сильного»);
нейтральное; пустое (никого).

## D. КАК РАСПОЛОЖЕНЫ — отношения (по канону)

Уровень **гекса**:
- на том же гексе;
- **соседние гексы** (общая сторона);
- линия из N гексов подряд; кольцо вокруг гекса (все 6 соседей / N из 6);
- гекс **окружён** (все проходимые соседи заняты …);
- расстояние ровно / не больше N;
- зона стройки (свой гекс со зданием + за свободной стенкой).

Уровень **ячейки** (сектора и небо; канон 13.08):
- **соседствует** — соседняя ячейка в том же гексе или через ребро;
- **примыкает** — только через общее ребро двух гексов;
- техника — две ячейки; здание — свой след; авиация в небе соседствует со всеми
  наземными ячейками своего гекса.

**Куда смотрит** (стенки):
- стенка здания обращена к гексу, где есть …;
- за стенкой (гекс по ту сторону стенки);
- стенка к стенке (две стенки на общем ребре);
- проход закрыт / открыт (чужая стенка на ребре).

## E. ФИГУРА — рисунок на сетке

Канон 12.08: на карте нарисована гексовая сетка; фигуру можно **вращать и
сдвигать, нельзя отражать**. Клетка рисунка несёт метки из B и C (кто, чьё) или
«пусто»/«любой». Два масштаба:

- **гексовая фигура** — клетка = гекс (крупно, читается сразу, 1–5 гексов);
- **ячеечная фигура** — клетка = ячейка (тонко: «техника примыкает к казарме
  стенкой к врагу»).

Перебор форм — программой: связные формы из 1–5 гексов без учёта поворотов:
1, 1, 3, 7, 22.

## F. ЧТО СЛУЧИЛОСЬ В ЭТОТ ХОД — происшествия

- уничтожил: **что** (из B) + **кем** (род атакующего) + **какой атакой**
  (универсальная / специальная) + **откуда** (с гекса в фигуре / из-за стенки /
  с неба);
- нанёс N урона за ход; уничтожил N жетонов на одном гексе;
- построил: что, какой номер, где (рядом с чем, в фигуре);
- перемещение: сколько жетонов, на сколько гексов, мимо чего, **закончил в
  фигуре**; телепортация;
- выпустил: что, сколько; добыл: сколько, откуда; накрыл контейнер;
- Наука/Рынок: чем заплатил, сколько способов;
- получил урон / потерял жетон (задания «от обратного»).

## G. СЧЁТЧИКИ — не на поле

ресурсы (монеты, келемий, боеприпасы, трофеи; «ровно», «не меньше», «ноль»);
свалка (сколько, чьих, каких); треки Науки (ступень); модули (какие, где);
установленный арсенал (сколько, каких); запас (род кончился); карты в руке.

## H. ЧТО ДАТЬ — эффекты

Разовые (награда задания, верх, спец-способность):
- ресурсы; ветка действия / целое действие-развилка; спец-действие;
- атака: бесплатная, **кем** (род), по чему; урон; снять урон;
- перемещение (кем, на сколько), телепортация; щит; +скорость;
- развёртывание / десант; энергия (переложить, получить кубик);
- **здание**: поднять номер (заменить на следующий из запаса), построить даром,
  повернуть здание (сменить, куда смотрят стенки);
- карты: взять, посмотреть 2 оставить 1, сбросить и взять, вернуть сожжённую;
- модули: переставить, позолотить; Наука: шаг.

Постоянные (арсенал, слой ПОВЕРХ нынешнего эффекта — решение 30.09):
- «пока фигура стоит — …»: войскам в фигуре +скорость / +атака / +прочность;
  стенки фигуры не пропускают авиацию; жетоны фигуры нельзя телепортировать;
- «когда собрал фигуру — …» (срабатывание один раз за ход);
- «когда выполняешь задание / сжигаешь карту — …» (связки карта + карта).

## I. КТО КОГО — точки противостояния

- специальная атака рода бьёт только изображённый тип (готовый «треугольник»);
- здания закрывают войска от наземных атак; авиация бьёт всех;
- стенки закрывают проход и выстрел; чужие наземные войска перекрывают гекс;
- ломать чужую фигуру: занять её гекс, закрыть ребро стенкой, выбить жетон.

## J. ЦЕЛИ (метки для каждой карты — мета Влада)

блокировать · обмануть · уйти от удара · уничтожить · набрать очки ·
раскачать движок.
