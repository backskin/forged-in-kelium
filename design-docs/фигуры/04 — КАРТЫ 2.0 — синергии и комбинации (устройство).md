# КАРТЫ 2.0 — синергии и комбинации (устройство, 30.09.2026)

Поправка Влада 30.09.2026: жирная ставка не на фигуры, а на **синергии и
комбинации за ход и на несколько ходов**, многоходовочки по картам. Карты —
самая жирная и важная часть игры. Образцы: «Руины острова Арнак», «Дюна:
Империя», «Загадочные существа». Фигура остаётся одним из кирпичиков
требований, не основой.

Всё ниже — словарь, из которого карты собирает ПРОГРАММА (принцип «не
подгонять задачу к ответу» в силе). Здесь нет готовых карт.

## 1. Что берём у образцов и как это ложится на наши компоненты

| Образец | Приём | У нас |
|---|---|---|
| Арнак | действие-молния: сыграл и ходишь дальше; цепочка карт внутри хода | **спец-действие** — валюта цепочки: награда «+спец-действие» и разыгрывание «не тратя спец-действие» |
| Арнак | артефакт: купил — сразу сыграл | карта, взятая в этот ход, сразу разыгрывается (верх или установка) |
| Дюна | у карты два применения, одно исключает другое | уже есть: верх (сжечь) или низ (установить / выполнить) |
| Дюна | налог с чужих действий | «каждый раз, когда соперник … на твоём гексе / рядом с твоим зданием» |
| Существа | карта в табло срабатывает каждый раз при действии, которое ты и так делаешь | низ арсенала: «каждый раз, когда играешь ветку X — Y» |
| Существа | счётчики символов | значок развилки на карте: «за каждую свою установленную карту со значком …» |
| Существа | батарейка: жетоны на карте, не больше одного за ход | ресурс, лежащий на установленной карте: «положи сюда; потрать отсюда» |
| Существа | потолок на каждой связке, напечатан | «не больше N раз за ход», «не больше N ★» на самой карте |
| Существа | бесплатный розыгрыш «не считается действием» | «выполни задание, не тратя спец-действие» |

Ограничения, которые не нарушаем:
- перед игроком открыт только установленный арсенал (провал 27.09) —
  постоянные эффекты живут ТОЛЬКО на установленном арсенале, выполненные
  задания уходят в сброс;
- правило читается с компонента: предел, род срабатывания, батарейка —
  значком на карте;
- только настоящие термины игры.

## 2. Роды срабатывания установленной карты (значок в углу низа)

1. **Постоянно** — правит правило (цена, скорость, прочность, выпуск).
2. **Каждый раз, когда …** — событие + эффект + предел за ход.
3. **Спец-действием** — «потрать спец-действие: …».
4. **Сразу при установке** — разовый эффект в миг установки (к верху
   прибавка для той же карты: сжечь ИЛИ установить с малым сразу).
5. **В конце партии** — очки по счётчику, с потолком.
6. **Батарейка** — на карте лежат ресурсы; эффект «положи» и эффект
   «сними и получи», не больше одного раза за ход.

## 3. События (из потока событий движка)

Свои: сыграл ветку (по каждой из десяти), выполнил задание, сжёг карту
(задания / арсенала), установил карту, вскрыл контейнер, взял карту
(задания / арсенала), уничтожил жетон (что · кем · какой атакой), получил
урон / потерял жетон, построил (что), нанял (что), шаг Науки, предложение
Рынка, совпадение приказов, открылся низ, Обновление, Возвращение.
Чужие (налог): соперник вошёл на соседний с твоим зданием гекс, соперник
сыграл ту же карту приказа, соперник атаковал тебя.

## 4. Эффекты (что даёт)

Ресурсы; карта задания / арсенала (в руку, «посмотри 2, оставь 1»);
**+1 спец-действие в этот ход**; ветка действия (любая из десяти, «вне
приказов»); «следующее задание выполни, не тратя спец-действие»;
перемещение одного жетона; атака одним жетоном; снять урон; построить;
нанять; переложить кубик энергии; шаг Науки со скидкой; «−1 к цене»;
очки ★ (с потолком).

## 5. Требования заданий — связки через карты

Кроме стола (кирпичики каталога, фигура — один из них) требования
спрашивают о КАРТАХ хода — это и есть многоходовочка по картам:
- «в этот ход выполни второе задание» (цепочка);
- «в этот ход сыграй обе ветки одной развилки»;
- «в этот ход сожги карту и выполни задание»;
- «имей установленными 2 карты со значком …»;
- «в этот ход получи 3 спец-действия».

Награда задания — ветка действия, как сейчас, плюс её значок развилки.
Награда ветки выполняется сразу — так награда одной карты делает
требование следующей (цепочка за ход), а установленный арсенал платит за
ветку (двигатель).

### 5.1. Узлы требования (данные карты)

| узел | печатается | проверка |
|---|---|---|
| жетоны | «Имей на поле N своих запитанных добытчиков» | счёт по столу |
| рядом | «Имей своё военное здание на гексе, соседнем с гексом, где есть войска врага» | пары гексов |
| фигура | рисунок до 4 гексов | повороты без отражения |
| ветки | «В ЭТОТ ХОД сыграй Добыть и Бой» | журнал хода |
| обе ветки | «В ЭТОТ ХОД сыграй обе ветки Командования» | журнал хода |
| задания | «В ЭТОТ ХОД выполни это задание вторым» | журнал хода |
| сжёг / установил | «В ЭТОТ ХОД сожги карту» | журнал хода |
| уничтожь | «В ЭТОТ ХОД уничтожь здание врага техникой» | журнал (кем · какой атакой · откуда) |
| построй / найми | «В ЭТОТ ХОД построй 2 здания» | журнал хода |
| спец | «В ЭТОТ ХОД используй третье спец-действие» | журнал хода |
| ресурс | «Имей 6 монет» | хранилище |
| арсенал | «Имей 2 установленные карты со значком Добычи» | ячейки под планшетом |
| свалка | «Имей на свалке 2 жетона врага» | свалка |

## 6. Значок развилки на каждой карте

Каждая карта задания и арсенала несёт один значок из пяти (Добыча,
Питание, Снабжение, Командование, Развитие); редкие — два. Значок
считают требования («2 установленные карты со значком Командования») и
счётчики («+1 монета за каждую свою карту со значком Добычи, не больше 3»).
Значки дают **стратегии**: пять дорог, у каждой свой двигатель.

## 7. Измерение (как программа отличает живую карту от мёртвой)

- **Сила хода**: поиск лучшей последовательности решений своего хода из
  позиций настоящих партий (пошаговый API); ценность — прирост по курсу
  таблицы карт (`ТаблицаКарт.КУРС`). Сила карты = прирост с картой минус
  без неё.
- **Связка**: сила(А и Б) − сила(А) − сила(Б). Положительная — синергия.
  Так строится таблица связок всего набора.
- **Многоходовочка**: то же на горизонте двух-трёх своих ходов.
- **Стратегия** — группа карт, связанных сильными связками; число групп
  и ровность их силы — главное мерило набора.
