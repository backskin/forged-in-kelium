Командный пункт

Экран живой партии для hot-seat и (позже) сети. Поле — всегда в центре и никогда не прячется; всё остальное — панели вокруг него. Каждый элемент управления на этих макетах привязан к настоящей точке решения движка (моно-теги вида build_hex) — здесь нет ни одной кнопки, под которой не было бы готового кода движка.

Концепт на утверждение — код не пишется, пока макеты не согласованы

Поле — якорь

Центр экрана всегда занят полем. Наука, рынок, чужие планшеты — выезжающие панели поверх, не вкладки и не отдельные экраны.

Обратимое — мгновенно, необратимое — через крупное «да»

Стройка/добыча/манёвр/энергия/сборка играются без подтверждений и откатываются по клику. Бой и рынок — одно крупное подтверждение с предпросмотром последствий.

Всё в один клик

Любой факт партии — не дальше одного клика или наведения: полный текст карты по hover, слагаемые счётчика в подсказке, чужой планшет в ящике.

Выбираешь на поле, а не в списке

Гекс, сектор, цель атаки — кликом по самому полю с подсветкой легального. Кнопки остаются только для именованных вариантов (действия, треки, ставки).

Ничего не телепортируется

Чужой ход проигрывается шаг за шагом с подсветкой места события и кнопкой «пропустить». Каждое событие дублируется строкой в ленте.

Честный экран

Скрытая информация чужих мест не попадает на экран никогда. Между людьми — шторка передачи устройства с явным подтверждением «это я».

2Шаги хода. Каждое сыгранное действие — строка. Клик «⟲ сюда» откатывает к этой точке (стек снимков уже в движке). Замок — необратимое: приказ, бой, рынок. Ниже — лента всей партии.

4Панель действий. Все 8 действий всегда видны; недоступные — серые с причиной. Клик по доступному запускает действие. Под ними СПЕЦ-действия. action spec_*
5Завершить ход. Показывает остаток; если остались обязательные решения — говорит какие, а не молча блокируется. Это и есть pass верхнего меню.
ЭКРАН 2

Стройка — призрак и секторы

Игрок выбрал «Энергостанция L1» из меню стройки. За курсором ездит полупрозрачный призрак; легальные гексы обведены, у гекса под курсором раскрашены СЕКТОРЫ: зелёные — дуга встанет, красный — сектор занят. Колесо мыши вращает дугу по гексу.

ЭКРАН 3

Бой — необратимое действие

Единственное место в своём ходу, где интерфейс останавливает игрока крупным подтверждением: бой виден всем сразу, откатить его нельзя. Поле пригашено, источник и цель подняты над затемнением, между ними стрелка.

ЭКРАН 4

Чужой ход и передача устройства

Слева — ход бота: события проигрываются по одному, место события пульсирует, всё дублируется лентой; панели и подсказки остаются живыми. Справа — шторка между людьми: рука следующего игрока не откроется, пока он сам не нажмёт «Это я».
