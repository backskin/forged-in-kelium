# Скрипты подсчетов для экспертизы правил

Этими скриптами получены числа в словарях и в своде о визуальном языке.
Они читают образцы из `образцы/рулбуки/` в корне репозитория.

- `corpus.py` - делит тексты десяти русских книг на предложения и считает
  обороты. `python corpus.py size` показывает объем корпуса; `python
  corpus.py count связки.txt core` считает шаблоны из файла по книгам;
  `python corpus.py show "<шаблон>" core 3` печатает примеры предложений
  с номером страницы. Вместо `core` можно написать `all`, тогда к десяти
  книгам добавятся еще десять неразобранных.
- `связки.txt` и `слова.txt` - списки шаблонов: связки и вводные слова;
  слова для вещей и действий.
- `measure.py` - снимает с PDF формат, кегль, интерлиньяж, ширину колонки,
  знаки в строке, поля и плотность. Папки с исходными PDF задаются
  переменной окружения `RULEBOOKS_DIR`.
- `layout.py` - печатает блоки текста и картинок страницы с координатами
  в процентах полосы: `python layout.py "<файл.pdf>" 1 16`.

Нужен Python с библиотекой PyMuPDF.
