# Спец-плашки карт приказов — по фракциям

**Черновик на бумаге.** Ничего не меняет: ни правила, ни свод, ни код. Записан,
чтобы раскладка не жила в переписке.

Заказ дизайнера 07.09.2026: снять малую плашку перемещения с одной карты из
четырёх, добавить вместо неё выдачу карты задания и развести три спец-действия
по фракциям так, чтобы у каждой был свой набор — не только нижних приказов, но
и спецов.

---

## 1. Слова поменялись местами

- **Действие** приказа ОПЕРАЦИЯ теперь называется **МАНЁВР** (было Движение).
- **Спец-плашка** на карте приказа теперь называется **ДВИЖЕНИЕ** — перемести
  один свой жетон на его скорость (была «манёвр с карты приказа»).

Это важнее, чем кажется. Если бы переименовали только действие, плашка «манёвр
одним войском» столкнулась бы с ним ровно так же, как приказ ОПЕРАЦИЯ
столкнулся с операциями Стройки днём раньше. Обмен именами закрывает вопрос
целиком: каждое слово занято один раз.

## 2. Три спец-плашки вместо одной

| Плашка | Что даёт |
|---|---|
| **ДВИЖЕНИЕ** | перемести один свой жетон на его скорость |
| **МОНЕТА** | возьми 1 монету |
| **ЗАДАНИЕ** | возьми 1 карту задания |

Было: плашка на восьми картах из шестнадцати, и всегда одна и та же —
перемещение. Стало: плашка на двенадцати картах, но **перемещений всего четыре
на всю игру вместо восьми**. Спец перестал быть «почти всегда лишний шаг
войском» и стал признаком фракции.

## 3. Правило, из которого выведена раскладка

> **Спец на карте не кормит её собственный верхний приказ.**

Одно правило вместо таблицы запретов. Два запрета дизайнера — его частные
случаи: движение нельзя на карту с верхом ОПЕРАЦИЯ (там и так Манёвр и Бой),
монету нельзя на карту с верхом ИНФРАСТРУКТУРА (там Стройка её и тратит).
Третий запрет дописан по той же логике: задание нельзя на карту с верхом
ПРИОБРЕТЕНИЯ, потому что Рынок задания и выдаёт.

Монета вдобавок не идёт и в РАЗРАБОТКУ — по семьям ресурсов, которые уже
работают в наградах заданий: монета кормит Разработку и Инфраструктуру,
боеприпас — Операцию, контейнер — Приобретения. Тот же принцип, ни одного
нового.

## 4. Раскладка

Найдена перебором по трём условиям сразу: правило выше соблюдено везде; карта
БЕЗ спеца у каждой фракции стоит на своём приказе; каждый спец разбросан по
разным приказам, насколько запреты позволяют.

| Колода | Верх / Низ | Спец |
|---|---|---|
| **Голубая** | Инфраструктура / Разработка | — |
| | Разработка / Операция | **ДВИЖЕНИЕ** |
| | Операция / Приобретения | **ЗАДАНИЕ** |
| | Приобретения / Инфраструктура | **МОНЕТА** |
| **Алая** | Инфраструктура / Приобретения | **ДВИЖЕНИЕ** |
| | Приобретения / Операция | — |
| | Операция / Разработка | **МОНЕТА** |
| | Разработка / Инфраструктура | **ЗАДАНИЕ** |
| **Зелёная** | Инфраструктура / Операция | **ДВИЖЕНИЕ** |
| | Операция / Инфраструктура | — |
| | Разработка / Приобретения | **ЗАДАНИЕ** |
| | Приобретения / Разработка | **МОНЕТА** |
| **Жёлтая** | Инфраструктура / Разработка | **ЗАДАНИЕ** |
| | Разработка / Приобретения | — |
| | Приобретения / Инфраструктура | **ДВИЖЕНИЕ** |
| | Операция / Операция | **МОНЕТА** |

Карта без спеца: Голубая — Инфраструктура, Алая — Приобретения, Зелёная —
Операция, Жёлтая — Разработка. Все четыре разные.

Разброс: ДВИЖЕНИЕ стоит на трёх разных приказах, ЗАДАНИЕ на трёх, МОНЕТА на
двух. Шире монета не расходится в принципе — ей открыты только Операция и
Приобретения.

## 5. Что из этого читается как характер фракции

**Жёлтая — самая странная, и это хорошо.** У неё единственная в игре карта, где
верх и низ совпадают (Операция / Операция), и на ней стоит МОНЕТА: чистая
военная карта ещё и финансирует. Карта без спеца у неё на Разработке.

**Голубая — зеркальный случай.** Карта без спеца на Инфраструктуре, а монета
приходит с Приобретений: самая хозяйственная колода по ощущению.

**Алая и Зелёная** отличаются одной перестановкой: у обеих ДВИЖЕНИЕ на
Инфраструктуре, но у Алой монета на Операции, а у Зелёной — на Приобретениях.
Это самая тонкая пара, и если фракции нужно развести сильнее, разводить надо
именно её.

## 6. Что осталось нерешённым

- **Держится ли рамка целиком** — без подтверждения набор не собирается и в
  рулбук не переносится.
- **Сколько даёт плашка МОНЕТА** — одну монету или больше. Взята одна: спец
  один за ход, и он конкурирует с розыгрышем задания и карты арсенала.
- **Плашка ЗАДАНИЕ — тянуть вслепую или из открытых.** Взято «возьми 1 карту
  задания», то есть вслепую, как обычный добор.
- **Приложение А рулбука** сейчас описывает старую плашку на восьми картах и
  подлежит замене вместе с принятием этой раскладки.
