# Задания 7.0 — каталог (2026-08-11)

Исправленная версия 6.0 по результатам аудита («Задания 6.0 — аудит по 7
вопросам»). Все карты прогнаны через структуру хода: один вскрытый приказ,
один СПЕЦ, ответный бой в чужой ход, ЦУ производит вышку, чужие здания
непроходимы для наземных. Тарифы щедрости, поправки к конструктору (⚠ 1 ТРФ в
базе карт-убийств; верхи строго из каталога А/Б; тарифная сетка) — как в 6.0.

Правило, добавленное после аудита, — **тест одного приказа**:
> Эпизод «в этот ход сделал X и Y» допустим только если X и Y — действия
> ОДНОГО приказа (Сборка+Добыча, Стройка+Смена энергии, Движение+Бой,
> Маркет+Наука) либо действие+свободное действие.

Обозначения: С = состояние, Э = эпизод «в этот ход», Ж = жертва.
Особая награда всегда включает **+1 карту задания**. [4] — убрать втроём и
вдвоём, [3+] — убрать вдвоём.

## Начальные задания (n1–n8) — горизонт 2–3 круга

Награда прежняя: 1 ТРФ + карта задания. Правило калибровки: порог = старт +
минимум 2 осмысленных действия, одно из которых требует предварительной
постройки или запитки; и НИКАКИХ условий, закрываемых стартовым набором
(ЦУ+добытчик+пехотинец, 5 МОН / 1 КЕЛ / 1 БПР) или вышкой из ЦУ.

| ID | Название | Условие | Почему круги 2–3 |
|----|----------|---------|-------------------|
| n1 | Подъём | ≥5 зданий на поле | старт 2; три стройки с надбавками — деньги двух-трёх ходов |
| n2 | Первый призыв | произвёл пехоту, технику или авиацию в этот ход | вышка ЦУ не считается: нужно построить И запитать военное здание |
| n3 | Боезапас | ≥4 БПР в запасе | старт 1; сборка ЦУ + маркет — два-три хода самоотдачи |
| n4 | Первая сделка | совершил ≥2 РАЗНЫХ напечатанные сделки за ход | нужно 2 КЕЛ в кармане — сначала добыча; учит все четыре курса |
| n5 | Энергосеть (старт) | ≥2 запитанных здания (не ЦУ) | станция → Смена энергии → два потребителя |
| n6 | Выход | войско в ≥2 гексах от твоего ЦУ | пехота со скоростью 1 — два действия Движения |
| n7 | Жила | ≥3 КЕЛ в запасе | старт 1 + две добычи; ⚠ сверить со стартовой ёмкостью хранилища |
| n8 | Находка | вскрыл ≥1 контейнер в этот ход | добытчик (запитать) или проход войском по полю |

## Движку (objectives.1.5.0)

Новые/изменённые предикаты против реестра ~46:

1. `produced_and_mined_this_turn` (o01) — оба факта в журнале есть.
2. `assembly_total_output ≥ N` (o03-усил) и `ammo_produced_this_turn ≥ N` (o08).
3. `produced_at_building_type` (o02-усил: авиабаза).
4. `powered_miner_at_central_grid` (o04-усил) — spawn_is_start уже различается.
5. `unit_kinds_on_field(exclude=tower) ≥ N` (o07).
6. `sacrifice_unit_near_enemy` (o06) — войско на/рядом с гексом с чужими жетонами.
7. `building_on_hex_with_enemy_units` (o12) — существующий building_on_hex_with_enemy
   сузить до войск.
8. `moved_building_not_cu` / `moved_miner_now_at_grid` (o16).
9. `moved_and_destroyed_this_turn` (o26) — оба факта в журнале есть.
10. `unit_on_hex_with_enemy` (o27, o29-усил), `own_tokens_bordering_enemy_hex` (o28).
11. `damage_cubes_on_enemy_total/distinct` (o23), `destroyed_heavy_this_turn` (o22).
12. `aircraft_on_enemy_cu_hex` (o31-усил).
13. `used_market_card_offer` (o33-усил), `distinct_printed_deals_this_turn ≥ 2` (n4).
14. `resource_at_most` (o40), `modules_on_boards ≥ N` (o39).
15. n2: произведённый род ≠ вышка (фильтр по типу в журнале выпуска).

Верхи Б-III (щиты, ремонт, страховка, расчёт) — офф-тёрн хуки, в симе пока
no-op с пометкой. Проверка после кодирования — цели из части 6 документа 6.0
(мёртвых низов ≤6; усиления 15–30%; жертвы ≤15% выполнений; K обменников ≤1.5)
плюс новая: **каждый эпизод колоды обязан проходить тест одного приказа** —
автотестом по данным карт, не глазами.
