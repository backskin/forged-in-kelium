# Карты приказов — полная таблица

Источник правды по составу колод приказов: что на какой карте напечатано и какими колодами играют.

---

## 1. Названия

**Четыре приказа, по два действия в каждом:**

| Приказ | Действия |
|---|---|
| **РАЗРАБОТКА** | сборка · добыча |
| **ИНФРАСТРУКТУРА** | стройка · смена энергии |
| **ОПЕРАЦИЯ** | движение · бой |
| **ПРИОБРЕТЕНИЯ** | маркет · наука |

**Пятая карта в руке — БЕЗОПАСНОСТЬ.** Название напечатано на карте.

«Разработка» описывает содержимое приказа буквально: сборка юнитов, производство боеприпасов и добыча ресурсов.

**Слова, запрещённые в лексиконе игры:** приказ «Развитие» · приказ «Спецоперация» · действие «Рынок». Место торговли — это **планшет маркета** и **карты маркета**, а действие называется **Маркет**.

---

## 2. Что напечатано на карте

### Шапка приказа (верхняя половина)

Стрелка-нашивка с названием приказа, под ней — **формула розыгрыша**:

> **▶ + 1!  ·  👤 : 2≠●  /  👤+👤 : 1●**

Читается так:

| Знак | Значение |
|---|---|
| **▶** | Вскрытие карты |
| **1!** | Плюс одно СПЕЦ. действие в этот ход |
| **👤 : 2≠●** | Ты **единственный**, кто вскрыл этот приказ → играешь **2 разных действия** |
| **👤+👤 : 1●** | Приказ вскрыл **кто-то ещё** → играешь **1 действие** |

Это правило совпадения, напечатанное на самой карте. Отдельного объяснения в правилах оно не требует.

### Два действия приказа

Круглые иконки с подписями. Всегда ровно два — приказы симметричны.

### Плашка манёвра — на восьми картах из шестнадцати

> **! : ↷ 1×🔫**

**СПЕЦ. действие: перемести один свой жетон войска на его скорость.** Бесплатно, одно перемещение.

Это не действие Движение целиком — это **один сдвиг одним жетоном**, и он не открывает Операцию.

### Нижняя половина — второй приказ

Перевёрнутая шапка с иконкой «приказ соседа», название второго приказа и его два действия. Если хотя бы один соперник вскрыл этот приказ сверху в этот круг, ты можешь выполнить **одно** действие с нижней половины. Внизу карты — напоминание **1●**.

## 3. Словарь иконок

| Иконка | Значение |
|---|---|
| **▶** — кружок с треугольником | Вскрытие карты приказа |
| **!** — кружок с треугольником и восклицанием | СПЕЦ. действие |
| **●** | Одно действие |
| **2≠●** | Два **разных** действия |
| **↷** — стрелка со сгибом вправо | **Одно перемещение** (не действие Движение целиком) |
| **🔫** — автомат на наклонённом параллелограмме | **Один жетон любого своего войска**: пехота, техника, авиация или вышка |
| **👤 / 👤+👤** | Один игрок вскрыл приказ / вскрыли несколько |

**Про иконку войска.** По умолчанию она означает **один** жетон и **любой** род. Число рядом меняет количество, отсутствие числа читается как единица. Принадлежность — всегда тому игроку, к кому обращено правило.

### Четыре карты БЕЗОПАСНОСТЬ

По одной на колоду, пятая карта в руке каждого игрока.

| Что напечатано | Значение |
|---|---|
| Формула **▶ + 2≠●** | Всегда два разных действия. Правила совпадения нет |
| Все восемь действий игры | Стройка · смена энергии · сборка · добыча · движение · бой · маркет · наука |
| Нижнего приказа нет | — |

**БЕЗОПАСНОСТЬ не подавляется** правилом совпадения и **у соперников не считается вскрытым приказом**. Её формула короче именно поэтому: одна строка вместо двух.

## 5. Структура колод

**Плашка манёвра стоит ровно на тех восьми картах, где верхний приказ — Инфраструктура или Приобретения.** Это два приказа, действия которых почти не трогают поле: маркет и наука не трогают вовсе, стройка и смена энергии работают только со своим. Манёвр их компенсирует — даёт минимальное присутствие на карте, не открывая Операцию.

**Схема нижних приказов по колодам:**

| Колода | Отображение верх → низ | Тип |
|---|---|---|
| **Голубая** | И→Р · Р→О · О→П · П→И | Цикл по кругу И→Р→О→П→И |
| **Алая** | И→П · П→О · О→Р · Р→И | Тот же цикл **в обратную сторону** |
| **Зелёная** | И↔О · Р↔П | **Двойной обмен** |
| **Жёлтая** | И→Р · Р→П · П→И, **О→О** | Тройной цикл + **зеркало на Операции** |

**Две встречные ротации вместо двух обменов.** У голубого и алого игроков нижние приказы никогда не совпадают, потому что циклы идут в разные стороны. Двойной обмен даёт симметрию, а встречные циклы — асимметрию при той же простоте.

**Зеркало — точечное, а не системное.** Полностью зеркальная колода была бы самой сильной за столом: её нижний приказ срабатывал бы всякий раз, когда кто угодно повторяет её же приказ. Зеркало стоит только на Операции (карта 16) — то есть жёлтый игрок выигрывает от того, что за столом любят воевать, и ни от чего больше.

**Каждая колода содержит ровно по одной карте на каждый верхний приказ.** Значит любой игрок в любой круг может сыграть любой из четырёх приказов — колода не ограничивает стратегию, только то, что достанется в нижней половине.

## 6. Как это работает в раунде

1. **Слепой сброс карты приказа.** Не глядя, одна из пяти карт откладывается рубашкой вверх горизонтально — место для трофеев на раунд. Игрок берёт оставшиеся 4 в руку и видит, чего лишился.
2. **Четыре круга.** В каждом все одновременно выкладывают и вскрывают карту приказа, розыгрыш по часовой от первого игрока.
3. **Возврат.** Все 5 карт в руку.

**Следствие слепого сброса:** каждый раунд у игрока выпадает один случайный приказ. Если это была БЕЗОПАСНОСТЬ — раунд играется без неё; если Операция — раунд без войны, кроме как через нижние приказы и карты.
