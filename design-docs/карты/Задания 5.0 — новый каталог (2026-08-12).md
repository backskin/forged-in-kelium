# Задания 5.0 — новый каталог (версия base-2026-08-12)

Полный рерайт 40 обычных заданий. Цель: **достижимые низы, берущиеся усиления,
разнообразие путей, живая геометрия** (в т.ч. примыкание СТЕНКОЙ). Пороги
откалиброваны по реальной игре ботов (замер 80 партий 4p, обученный стратег):

- юнитов на поле: макс 9, среднее 2;  зданий: макс 11;  военных зданий: макс 2;
- добытчиков: макс 4;  боеприпасов: макс 10;  келемия: макс 12;  трофеи-пул: макс 6;
- за ОДИН ход: обычно 0–1 юнит из сборки, 0–1 перемещение (2+ — редкость).

Отсюда правила калибровки:
- **state** (состояние на поле) — пороги в зоне достижимого (3–5 юнитов, 2 разных
  военных здания, 4+ ammo, ~4 зданий), усиление на +1–2 сверху (берётся, но не даром);
- **incident** (событие за ход) — только объёмы, реально делаемые за ход:
  produced ≥1 (не ≥2!), moved ≥2, destroyed ≥1, damaged ≥1, opened container ≥1;
- **sacrifice** (жертва) — цена по карману (2–4 ресурса);
- усиление = ощутимо труднее базы, но НЕ вдвое (цель 15–30% взятия, не 1%).

## Структура карты (напоминание для кода)
Низ = requirement (+ опц. enhanced). Верх = top (сжечь ради мгновенного эффекта).
Награда база всегда; special при enhanced; кросс-приказ: верх из ДРУГОГО приказа.

## Что изменилось против 4.0 (и почему)
1. **Убраны недостижимые пороги «за ход»**: produced ≥2 → ≥1; moved ≥3 → ≥2;
   containers ≥2 → ≥1. Раньше это делало 27/54 заданий мёртвыми.
2. **Усиления смягчены** до +1–2 от базы (цель 15–30% взятия вместо 1%).
3. **Новая геометрия «стенка к стене»** (o13, o17) — использует новый предикат
   `buildings_share_wall` (примыкание СТОРОНОЙ, не просто соседние гексы).
4. **Разнообразие путей**: A армия/ресурсы, B база/геометрия, C война/экспансия,
   D экономика/наука — каждая ветвь ведёт к своей тактике (реиграбельность).
5. **Модули как награда** распределены: атаки (война), сборки (армия),
   хранилища (экономика) — раньше почти только сборки.
6. Верхи (top) остаются кросс-приказными; про-военные (бой/урон/движение) на
   не-операционных картах, мирные (добыча/сборка/ресурс) на операционных.
