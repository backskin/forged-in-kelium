# Решения по игре и разработке

Всё, что не правила напрямую, но фиксирует решения по игре, инструментам и
процессу. Раньше жило россыпью в рабочей папке дизайнера на Яндекс.Диске —
теперь только здесь.

- `ЖУРНАЛ РЕШЕНИЙ.md`, `БЭКЛОГ — открытые вопросы.md` — текущий статус и история решений.
- `ЗАКАЗ — *.md` — постановки задач на инструменты (проигрыватель, справочник, цифровая версия).
- `АРСЕНАЛ *.md`, `КОНТЕЙНЕРЫ — каталог для дизайнера *.md` — рабочие заметки по балансу колод, отдельно от актуального каталога карт (актуальные данные — в `data/cards/`, актуальное описание — в `rules/generated/`).
- `карты/` — история итераций каталогов заданий/арсенала/контейнеров/маркета до текущей версии.
- `арт/` — гайды и промты для икон и иллюстраций.
- `анализ/` — разборы отдельных механик (например цикл контр между планшетами Б1–Б4).
- Остальные файлы — сессионные итоги, ревью интерфейсов, синхронизация между чатами, лор.

Правила игры (нормативный текст) — в `../rules/`.
