# Комплект «Пять действий-развилок» (27.09.2026)

Всё, что нужно цифровой версии, чтобы перейти на новые приказы и карты. Боты учатся после этого.

## Что внутри

| Файл или папка | Что это |
|---|---|
| `ПРАВИЛА — пять действий-развилок и приказы.md` | Правила: пять развилок, их ветки с кодами, ветка «построить», новые приказы, совпадение и низ, спец-плашки, что убрано. Как читать награды на неизменённых картах. Какие файлы данных задеты |
| `КАРТЫ — тексты и составы колод.yaml` | Текст каждой карты задетых колод: приказы, задания, начальные задания, арсенал, начальный и супер-арсенал, рынок. У каждой карты — путь к лицу и поле «изменено». Картинки вычитывать не надо |
| `лица/<колода>/<id>.png` | Полный набор лиц задетых колод, ширина 600, имена — точные id, как в `data/textures/card` |
| `лица-крупно/` | Перерисованные карты в печатном размере: 11 заданий и 7 карт арсенала |

## Где полный набор лиц

Папка `лица/` (139 файлов, около 90 МБ) лежит на Яндекс.Диске: `Forged in Kelium\комплект — пять развилок (27.09.2026)\лица`. Там же копия документов. В git её нет: неизменённые лица и так лежат в `data/textures/card`.

Собрать заново:

```
python tools/gen_komplekt_5.py                              # перерисовать изменённые карты
python "tools/собрать-комплект-5.py" "<папка назначения>"   # тексты и полный набор лиц
```
