# Карты и награды под пять действий-развилок (решение 27.09.2026): что задето

Источник: свод `data/rulesets/1.45.0.yaml`, content_versions: arsenal 7.2.0, super_arsenal 4.0.0, objectives 1.19.0 (40 обычных и 12 начальных), super_objectives 9.0.0, containers 6.0.0, market 4.0.0, orders 4.0.0, boards 3.2.0 (треки), modules 3.0.0. Движок: `Effects.freeAction`, `Objectives.grantBase` (награда «A|B» — выбор одного из двух), `GameEngine.resolveTurn`, `ability/*`.

**Как старые действия ложатся на развилки** (по этой таблице сделаны все оценки):

| старое действие (код) | куда уходит |
|---|---|
| Добыча (mining) | Добыча, ветка «Добыть» |
| Питание / смена энергии (energy_swap) | Питание, ветка «Переложить» |
| Снабжение / Снаряжение / Сборка (assembly) | Снабжение, ветка «Выпустить» |
| Манёвр (movement) | Командование, ветка «Манёвр» |
| Бой (combat) | Командование, ветка «Бой» |
| Рынок (market) | Развитие, ветка «Рынок» |
| Наука (science) | Развитие, ветка «Наука» |
| Стройка (build) | действия больше нет; стройка разошлась на три ветки: добытчик — в Добычу, энергостанция — в Питание, военное здание или ЦУ — в Снабжение |

**Два вида пункта (а).** Правка разного веса, поэтому в таблицах они разделены:
- **а1** — имя осталось именем ветки (Манёвр, Бой, Рынок, Наука, «добыча N добытчиками»). Правится только текст, сила не меняется.
- **а2** — имя стало именем развилки (Добыча, Питание, Снабжение/Снаряжение) или действие исчезло. Непонятно, что даёт карта — ветку или всю развилку, и от ответа зависит её сила.

**Допущение.** Предполагаю, что ветка «построить X» — это одна операция: построить одно здание своего рода или снести одно своё. Если ветка разрешает строить сколько угодно зданий своего рода, пункты о «двух зданиях за ход» (o12, o15, o65) становятся мягче.

## 10. Вопрос дизайнера: награды, которые давали целое действие

Для движка: пара «A|B» уже работает через `Objectives.grantBase`, и Командование = `movement|combat`, Развитие = `market|science` можно печатать без нового кода. Для Питания, Добычи и Снабжения целиком нужны коды веток стройки, например `build_miner`, `build_plant`, `build_military`. `Effects.freeAction` пускает только имена из `Actions.ALL_NAMES`, поэтому «build» (ops/fixed_price для a7_08/12/27) должен остаться там как под-действие, даже когда приказы его больше не дают.
