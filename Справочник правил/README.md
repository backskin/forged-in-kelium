## Откуда числа

Все таблицы собраны из машинных данных симулятора, а не переписаны руками:

- `simulator/data/rulesets/1.5.0.yaml` — действующая версия правил;
- `simulator/data/boards/boards.1.0.0.yaml` — планшеты;
- `simulator/data/cards/*.yaml` — карты;
- `simulator/data/scenarios/*.yaml` — раскладки поля.

Формулировки и логика — из `СВОД — механика игры (для работы над картами).md`.
Где СВОД и данные расходятся — см. `РАСХОЖДЕНИЯ.md` и раздел «Спорные места»
внутри приложения. Ничего не решено самостоятельно и не усреднено.

## Как пересобрать числа после правки данных

```bash
python "Справочник правил/tools/gen_content.py"
```

Скрипту нужен `pyyaml`. Он перечитает `simulator/data`, соберёт
`content/data.js` и напечатает размер файла. Больше ничего делать не надо —
приложение подхватит новые числа при следующем открытии.

Если поменялась версия правил, поправь `RULESET_ID` в начале скрипта:
версии остального контента он возьмёт из самого ruleset (`content_versions`).

## Горячие клавиши

- `/` или `Ctrl+F` — поиск по всему справочнику
- `Esc` — закрыть результаты поиска
- Кнопка «Печать» печатает текущий раздел; сворачиваемые блоки при печати
  раскрываются, оглавление и панели не печатаются.

## Чего приложение не делает

Оно только описывает существующие правила. Оно не правит правила, не трогает
`java-sim/` и `simulator/`, ничего не симулирует (кроме мелких проверок:
посадка жетонов в гекс, подсчёт очков, «сколько у меня действий») и никуда
ничего не отправляет.
