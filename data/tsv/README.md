# Листы карт в TSV

Сгенерированы из `docs/КАРТЫ — все таблицы.xlsx`
(`tools/сервер-таблиц.py`). Нужны, чтобы Google Таблицы могли забрать их
формулой IMPORTDATA по прямой ссылке: файловый импорт из браузера Google
не пускает, а данные карт и так лежат в этом репозитории открыто.

* `svodka.tsv` — Сводка
* `zadaniya.tsv` — Задания
* `nachalnye-zadaniya.tsv` — Начальные задания
* `super-zadaniya.tsv` — Супер-задания
* `arsenal.tsv` — Арсенал
* `nachalnyy-arsenal.tsv` — Начальный арсенал
* `super-arsenal.tsv` — Супер-арсенал
* `konteynery.tsv` — Контейнеры
* `rynok.tsv` — Рынок
* `util-zadaniy.tsv` — Утиль заданий
* `util-arsenala.tsv` — Утиль арсенала
