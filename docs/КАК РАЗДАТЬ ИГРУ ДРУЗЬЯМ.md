# Как раздать игру друзьям и держать у всех одну версию

## Один раз: публичная папка на Яндекс.Диске

1. На Диске уже есть папка `Forged in Kelium\Игра — раздача`. Откройте её
   свойства на disk.yandex.ru → «Поделиться» → «Скопировать ссылку» (вида
   `https://disk.yandex.ru/d/…`).
2. Положите эту ссылку одной строкой в файл `update-link.txt` в корне проекта
   (или просто пришлите её в чат — положу я).
3. Соберите игру: `powershell -ExecutionPolicy Bypass -File make-exe.ps1`.
   Сборка сама выложит в «Игра — раздача» запускатели и паки (~300 МБ в
   первый раз) и запишет ссылку внутрь раздачи.
4. Дождитесь, пока Яндекс.Диск досинхронизирует папку.

## Друг ставит игру (один раз)

- Скачивает папку «Игра — раздача» по ссылке целиком, распаковывает куда
  угодно, запускает `Играть.exe`.
- Windows может предупредить («Подробнее → Выполнить в любом случае»): exe не
  подписан.

## Дальше — само

- После любой новой сборки `make-exe.ps1` выкладывает только изменившиеся паки
  (обычно код и правила — единицы МБ; картинки — только если их меняли).
- У друга при каждом запуске игра сверяется со списком на Диске и докачивает
  изменившееся, с окошком прогресса. Скачанное проверяется по отпечатку.
- Нет интернета — игра запускается той версией, что есть.
- На машине сборки (там, где проект) обновление выключено: там и так
  свежая сборка.

## Сетевая партия

- Все в одной сети Radmin VPN (или ZeroTier/Tailscale).
- Хост: «Штаб» → «По сети» → «Создать стол»; брандмауэр при первом разе —
  «Разрешить» для Java.
- Друг: «По сети» → «Войти к другу» → адрес хоста в Radmin (26.x.x.x:47100).
- Версии у всех совпадают сами — благодаря обновлению выше; иначе лобби
  скажет «у вас другая версия правил».

## Код комнаты без Radmin

Нужен свой маленький сервер-посредник в интернете (аренда ~200–300 ₽/мес или
бесплатный тариф с картой). Пока его нет — только Radmin/ZeroTier.
