# «Анх. Боги Египта» (Ankh: Gods of Egypt): конспект свода

Эрик М. Лэнг, иллюстрации Эдриана Смита, CMON / Guillotine Games, 2021.
Русское издание «Лавка Геймз». Свод — 32 полосы (правила) + отдельная
книга сценариев. Прочитан целиком, с картинками (25.09.2026).

Контроль территорий на гексовой карте, 2—5 участников. Каждый — бог;
цель — поклонение. Особенность: **таймер партии движут сами действия
игроков**, а поле перекраивается по ходу игры.

---

## 1. Поле

- Карта Египта из шестиугольных клеток. Нил делит её на **три региона**
  (дельта, Восточный, Западный Египет).
- Клетки **плодородные** (зелёные), **пустынные** (жёлтые) и **водные**
  (синие). Водные занимать нельзя, но они считаются частью **каждого**
  соседнего региона.
- В клетке — ровно одна фигурка или один памятник.
- **Соседство только внутри региона**: клетки через реку или через
  караван верблюдов соседями **не считаются** — для всех правил.
- **Караваны верблюдов** — миниатюры на границах клеток; режут регионы
  на меньшие. Фигурками не являются.
- **Памятники**: обелиски, пирамиды, храмы. Контроль — жетон анха рядом.
  Нет жетона — памятник нейтрален.

## 2. Фигурки

- **Бог** — большая фигурка, **не погибает никогда**.
- **6 воинов** у каждого бога.
- **Стражи** — нейтральные существа трёх уровней (мумии, скорпионы,
  Апоп, андросфинксы, Сатис, мумии кошек), каждый со своим свойством.
- Базовая сила любой фигурки 1.

## 3. Центральный планшет — действия и события

- **Четыре шкалы действий**: переместить фигурки, призвать фигурку,
  получить верующих, открыть свойство анха. На каждой — фишка; выбрав
  действие, **сдвигаешь его фишку на деление вправо**. Стартовое деление
  зависит от числа игроков.
- Когда фишка доходит до последнего (белого) деления — **событие**: фишка
  событий сдвигается на шаг по **шкале событий**, событие разыгрывается,
  фишка действия возвращается на старт.
- **Ход — 1 или 2 действия**, но второе — только **ниже** первого на
  планшете. Если первое вызвало событие — второго нет.

Выходит, **темп партии общий**: каждый, выбирая действие, приближает
событие для всех. Можно намеренно довести шкалу до события в свой ход.

## 4. Действия

- **Переместить фигурки** — **каждая** твоя фигурка на 1—3 клетки,
  **сквозь** фигурки, памятники, воду, реки и верблюдов; закончить на
  пустой неводной клетке. Перемещение не меняет контроль памятников.
- **Призвать фигурку** — поставить воина или стража из запаса на пустую
  клетку, соседнюю с твоей фигуркой или с твоим памятником.
- **Получить верующих** — по одному за каждый памятник (твой **или
  нейтральный**) рядом с твоими фигурками.
- **Открыть свойство анха** — положить жетон анха с планшета бога на
  свойство; принести в жертву 1/2/3 верующих по уровню. Уровни по
  колонкам, не больше двух свойств на уровень, строго по порядку.
  Открылся символ стража — берёшь стража соответствующего уровня.

## 5. События

- **Контроль над памятником** (личное) — поставь анх у нейтрального
  памятника рядом со своей фигуркой; если нейтральных нет — перехвати
  чужой.
- **Караван верблюдов** (личное) — цепочка до 6 верблюдов делит регион
  на два, каждый не меньше 6 клеток; жетоны очерёдности конфликта можно
  переставить.
- **Конфликт** (общее) — по регионам в порядке жетонов очерёдности:
  - регион без фигурок пропускается;
  - **фигурки одного игрока — доминирование**: +1 поклонение за
    доминирование и +1 за каждый тип памятников, по которому у него
    большинство в регионе;
  - **фигурки нескольких — сражение**.
- **Слияние богов** (3+ игроков, после 3-го конфликта) — два бога с
  наименьшим поклонением сливаются в одного; игроки делят запас, свойства
  и победу, каждый делает одно действие в ход.
- **Забытые боги** — после 4-го конфликта все, кто остался в красной
  части шкалы поклонения, выбывают.

## 6. Сражение

1. Каждый тайно выбирает карту сражения (своя колода из 7), вскрывают
   разом. Разыгранная карта остаётся лежать лицом вверх — её нет в руке
   до «Цикла Маат».
2. «Возведение памятника» — по возрастанию поклонения: 3 верующих →
   памятник в регионе.
3. «Нашествие саранчи» — ставка верующими в кулаке; гибнут все воины и
   стражи в регионе, кроме сделавших наибольшую ставку.
4. Большинство памятников каждого типа — +1 поклонение.
5. Сила: 1 за фигурку + свойства + бонус карты. Победитель — +1
   поклонение, все вражеские воины и стражи гибнут. Ничья — жетон
   определителя ничьей (у того, чьё действие начало конфликт); без него
   все проиграли и все погибли.

## 7. Победа — три способа

1. Анх достиг верха шкалы поклонения — **немедленная победа**.
2. После 4-го конфликта остался один бог.
3. Иначе — наибольшее поклонение после последнего события.

## 8. Боги (асимметрия способностей)

- **Амон** — раз за конфликт две карты сражения сразу.
- **Анубис** — пленные вражеские воины усиливают его (до +3).
- **Исида** — её фигурки рядом с врагом защищены от гибели в сражении.
- **Осирис** — жетоны загробного мира: призыв на них, враги не могут там
  останавливаться.
- **Ра** — жетоны солнца: сияющие фигурки дают +1 к наградам поклонения.

## Что взять Келемию

1. **Нетронутый растёт сам.** Доминирование даёт поклонение без боя
   каждый конфликт. Остальным приходится идти в его регион. Это
   экономическая основа «того, кого не трогают, надо бить».
2. **Общий таймер из действий.** Шкалы действий — одна на всех; выбирая
   действие, приближаешь событие. Порядок событий виден на планшете.
   Альтернатива нашему фиксированному «8 раундов».
3. **Перемещение каждой фигуркой на 1—3 сквозь всех** — угроза с первого
   хода на небольшом поле; ограничение только «закончить на пустой
   клетке».
4. **Соседство только внутри региона** — граница (река, верблюды) режет
   соседство для всех правил сразу. Одно правило, читаемое с поля.
5. **Перекройка поля событием** (караваны) — игроки меняют карту
   конфликтов; меньшие регионы — больше доминирований.
6. **Против лидера:** «Нашествие саранчи», слияние двух отстающих,
   выбывание забытых. Слияние — редкий пример механизма, который
   помогает отстающим, не добавляя им ресурсов.
7. **Разыгранная карта лежит открыто** — соперники читают, что у тебя
   осталось. Информация о будущем бое — с компонентов.
8. Слабое: много исключений в свойствах стражей и богов; порядок
   применения эффектов («в обратном порядке по шкале поклонения»)
   повторяется в сноске за сноской.
