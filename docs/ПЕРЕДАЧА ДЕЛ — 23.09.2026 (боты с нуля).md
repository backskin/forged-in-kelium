# Передача дел — 23.09.2026: боты переписываются с нуля

Читать первым в новом чате. Условия работы с дизайнером — в прежней передаче
дел (`docs/ПЕРЕДАЧА ДЕЛ — 10.09.2026.md`) и в памяти; здесь — что сделано в

## Главное решение сессии

**Нынешние боты не умеют играть, и доработки это не лечат.** Дизайнер это
показал, подробный лог партии подтвердил (`kelium.ЛогПартии`,
`reports/logs/partiya_9100001.txt`): пасы при живых возможностях (жёлтый с
2 танками и 3 БПР пропускает Манёвр и Бой), «Стройка — ничего не построил»,
Наука без трофеев, Смена энергии туда-обратно, все четверо вскрывают
Безопасность в первом круге. Из ~8 доступных действий за раунд играется ~5.

**Причина в корне, а не в весах:**
1. Боты — написанные вручную эвристики + подобранные веса (геном). Обучение
   крутило числа внутри формулы; стратегии в формуле нет.
2. Движок не даёт думать вперёд: решения спрятаны внутри действий
   (`agent.choose(...)` посреди `perform`). Нет API «позиция → законные ходы →
   применить ход». Все «просчёты» проигрывали ход целиком чужой эвристикой и
   доигрывали той же слабой эвристикой.

Попытка «доигрывание до конца вместо формулы» поверх старого планировщика
провалена и откачена: 1 победа из 8, 6,5 ПО против 7,3 у гроссмейстеров.
**Больше не подкручивать старых ботов и не сравнивать с ними как с целью.**

## План (предложен дизайнеру, ждёт «да»)

1. **Движок: пошаговый API** — позиция, список законных ходов, применить ход,
   копия. Правила не меняются, меняется то, как бот разговаривает с движком.
   Без этого всё остальное бессмысленно.
2. **Бот: поиск по дереву (ISMCTS) + нейросеть, обученная самоигрой**
   (подход AlphaZero; скрытое — перемешивается при каждом просчёте). Никаких
   ручных формул и весов.
3. **Прозрачность:** в проигрывателе у каждого хода бота — какие варианты он
   рассматривал, сколько раз, с какой оценкой. Дизайнер не читает код и
   проверяет глазами.
4. **Критерий, видимый дизайнеру:** бот играет все свои действия, читает
   приказы соперников, уверенно обыгрывает нынешних ботов.

Честно сказано: несколько дней работы, обучение — часы/дни на машине
дизайнера, гарантии силы нет.

**Замер-опора:** партия быстрой эвристикой ~90 мс, ход ~0,7 мс, копия стола
~0,06 мс (`kelium.СкоростьСимуляции`). Честное перемешивание скрытого для
просчётов уже написано: `bots/.../agents/Доигрывание.перемешатьСкрытое`.

## Инструменты сессии

- `kelium.ЛогПартии [сид] [уровень]` — подробный лог: каждое решение бота
  (варианты, выбор), события, срез стола на каждом ходу.
- `kelium.ДугаПартии [партий] [уровень]` — по раундам: темп, выход цикла,
  табло, запасы, очки; фракции по кругу мест.
- `kelium.ПровалыДействий` — куда деваются действия (совпадения, пасы).
- `kelium.СкоростьСимуляции` — цена партии/хода/копии стола.
- Правки запуска для списков: `asymmetry.board_sides=green/blue/yellow/red`,
  `tech.step_coin=2/3/4/5`.
