# v1.50.0 — рабочая версия (02.10.2026)

Игра с набором карт 3.0 и всеми правками ветки на 02.10.2026.

**Как запустить.** Нужна Java 21 или новее (https://adoptium.net). Распакуйте
архив; Windows — «Играть.bat», macOS и Linux — `./играть.sh`. В «Штабе»
выберите свод правил: **1.50.0** — новейший набор карт, 1.46.0–1.49.0 —
прежние, для сравнения.

**Что нового против прежних сводов**
- Набор карт 3.0: 50 заданий и 12 начальных, 40 карт арсенала и 8 начальных,
  12 супер-заданий, 8 супер-арсенала. Задания и арсенал говорят энергией
  и уровнями зданий.
- Начальный арсенал: каждому две карты наугад, одну оставить.
- Жетоны хранилища двух видов (ячейка, энергия), со золотой стороной.
- Свободный верх задания (∞) «+1 спец-действие».
- Снос перед стройкой: ветка «построить» может снести свои здания того же
  вида (по монете за каждое) и поставить одно — хоть только что снесённое.
- Починка боя: окно реакций перед атакой могло отнять боеприпасы, и партия
  падала («нельзя оплатить 1 БПР») — теперь такой выстрел просто не
  состоится.

**Проверка перед выпуском.** Сборка со всеми тестами (окно игры — под
виртуальным экраном), затем из собранного архива — партии ботов на каждом
своде вдвоём, втроём и вчетвером до конца. Хоть одна красная — выпуска нет.
