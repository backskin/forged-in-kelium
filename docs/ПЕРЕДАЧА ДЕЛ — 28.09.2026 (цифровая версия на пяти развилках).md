## Как работать

- Сборка и тесты (одна за раз, не параллельно с правками):
  `mvn -o install -pl engine,cards,bots,gui -am` в папке ветки.
- Пересборка игры: `make-exe.ps1` в папке ветки.
- Обход партии глазами игрока перед сдачей:
  `kelium.gui.HotSeatTour <папка> [сид] [по N]` — играет целую партию за
  живое место и снимает окно на каждом виде решения. Редкие окна —
  `kelium.gui.HotSeatShot -Dshot.fake=reaction` и др. Каждый снимок смотреть
  глазами: видна ли причина вопроса, подсвечено ли место, понятно ли, куда
  жать, не закрыто ли плашками.
- Карты перерисовывать только с пустых шаблонов, иконками из
  `экспорт-иконки`, без обрезки.
- После любой правки из `main`, которая меняет правила в `1.45.0.yaml`,
  переносить тот же ключ в `1.46.0.yaml`.
