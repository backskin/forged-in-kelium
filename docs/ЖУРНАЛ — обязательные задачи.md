## Открыто

1. **Колоды мастерской — в свод.** Кнопка «В игру…» мастерской карт пишет
   `мастерская — задания.yaml` и `мастерская — арсенал.yaml` (папка
   `Общие компоненты/мастерская карт`). Подключить их к своду (новая версия
   свода с колодой мастерской или подмешивание в действующие колоды), чтобы
   карты мастерской выходили в партии. Поставлено 03.10.2026.

2. **Задания-фигуры — в бульон.** Узел языка «узор» (секторы гексов, поворот
   без отражения, авиация — джокер на один сектор своего гекса) есть в движке
   (`Figures.sectorsBest`, `Требование.Узор`). Добавить в `Бульон` кандидатов-узоры
   (2–3 гекса, 3–5 секторов, разные формы), прогнать замер, научить ботов
   выкладывать фигуры, собрать набор с заданиями-фигурами и арсеналом с условием
   «если на поле есть эта фигура». Поставлено 03.10.2026.

3. **Правило фигур — в книгу.** Глава о заданиях: закрашенные секторы занимают
   своими жетонами любого рода; фигуру можно поворачивать, отражать нельзя; своя
   авиация в гексе закрывает один любой недостающий сектор этого гекса (не больше
   одного). Свойство арсенала с фигурой работает, только пока фигура выложена.
   Поставлено 03.10.2026.

4. **Мастерская карт — замечания Влада 12.10.2026.**
   - «Эта карта / Весь каталог» непонятно: правка каталога не меняет текущую
     карту. Нужно: «Применить ко всем» (перенести правку карты в каталог);
     «Сбросить» на карте — вернуть к правилу каталога, на каталоге — сбросить
     правку каталога.
   - Цвет текста и обводки: цвет, толщина, обводка вкл/выкл — у каждого
     текстового элемента и значков (белая стрелка на белом поле карты рынка
     не видна).
   - Порядок слоёв: элемент выше/ниже соседних (стрелки ↑↓ в списке).
   - Кнопки «по центру по горизонтали / по вертикали».
   - Плашка реакции — строка, которую можно двигать вверх/вниз среди других
     строк и включать/выключать (крупные иконки вниз, текст вверх).
   - Значок слева по умолчанию у реакции — значок реакции (Влад поставил его
     вручную на карте 18).
   - Иконка «позолота» (улучшение модуля) вставляется мелкой — выровнять размер.
   - Две карты арсенала в награде — мелкие, поле вокруг огромное.
   - Звёзды арсенала (до 4) перекрывают карту — переделать.
   - Место для контейнера: уголки рамки — пунктиром, как стороны.
   - Плотность иконок в строке текста («+3 монеты» теснее); пробел между
     значками сейчас ни на что не влияет.
   - Рамки выделения на макете не по размеру объекта (например «−2 келемия»
     у спец-действия).
   - Награда «действие и ресурс» вместе — пока нечем нарисовать (подумать).
   - Пересобрать набор карт после правок.
   Поставлено 12.10.2026.
