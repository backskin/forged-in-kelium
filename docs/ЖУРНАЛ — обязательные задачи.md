# ЖУРНАЛ — обязательные задачи

Задачи, которые Влад велел не терять. Закрытую — отмечать датой и коммитом, не удалять.

## Открыто

1. **Колоды мастерской — в свод.** Кнопка «В игру…» мастерской карт пишет
   `мастерская — задания.yaml` и `мастерская — арсенал.yaml` (папка
   `Общие компоненты/мастерская карт`). Подключить их к своду (новая версия
   свода с колодой мастерской или подмешивание в действующие колоды), чтобы
   карты мастерской выходили в партии. Поставлено 03.10.2026.

2. **Задания-фигуры — в бульон.** Узел языка «узор» (секторы гексов, поворот
   без отражения, авиация — джокер на один сектор своего гекса) есть в движке
   (`Figures.sectorsBest`, `Требование.Узор`). Добавить в `Бульон` кандидатов-узоры
   (2–3 гекса, 3–5 секторов, разные формы), прогнать замер, научить ботов
   выкладывать фигуры, собрать набор с заданиями-фигурами и арсеналом с условием
   «если на поле есть эта фигура». Поставлено 03.10.2026.

3. **Правило фигур — в книгу.** Глава о заданиях: закрашенные секторы занимают
   своими жетонами любого рода; фигуру можно поворачивать, отражать нельзя; своя
   авиация в гексе закрывает один любой недостающий сектор этого гекса (не больше
   одного). Свойство арсенала с фигурой работает, только пока фигура выложена.
   Поставлено 03.10.2026.
