# ПРОМТЫ — восемь карт рынка (формат: Правило 16)

Общий формат для всех восьми (см. УРОКИ, Правило 16): квадрат 1:1, взгляд строго вперёд с высоты 2–5 м, кадр без видимого шва поделён вертикальной осью на две самостоятельные сцены, слитые общей линией земли/горизонта и единым светом. Для каждой карты ниже: краткая причинно-следственная предыстория (Правило 0, по-русски, только для внутренней логики — в сам промт не идёт), затем готовый английский промт целиком.

Стандартные обязательные блоки вставлены в каждый промт: FORMAT (Правило 16) в начале, ANTI-PHOTOREALISM дважды (сразу после FORMAT и в конце рядом со style-блоком), ERA / ANATOMY / PHYSICAL LOGIC / DENSITY (лимит 2–3 мелких предмета НА КАЖДУЮ половину) / COLOR-SEPARATION / STYLE, ARCHITECTURE-блок (Правило 15) там, где в кадре есть постройка, фракционный цвет (Правило 10) только там, где по сюжету реально показана фракция, каноничная броня пехоты (Правило 9) без слова armour, без оружейной лексики (gun/cannon/turret/weapon и т.д.).
